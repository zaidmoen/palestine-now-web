# تدقيق الفروع القديمة

يوثّق هذا الملف قرار ترحيل الفروع التي بدأت بتاريخ Git منفصل عن `main`. لا يمكن فتح Pull Request طبيعي منها دون إعادة كتابة تاريخها، لذلك تُنقل الأفكار المفيدة إلى فروع نظيفة مبنية على `main`.

| الفروع القديمة | الملاحظة | قرار الترحيل |
| --- | --- | --- |
| `Manar`, `ai-search-v2`, `log-in` | ثلاثة أسماء لنفس الالتزام، مع استدعاء AI مباشر من المتصفح | استبداله ببحث محلي آمن وقابل للاختبار؛ لا تُنقل بيانات الاعتماد أو الاتصال المباشر بالمزود |
| `students` | صفحة طالب فوق تاريخ منفصل | نقل أفضل الأجزاء إلى صفحة الطالب الحالية مع حفظ التقدم واختبارات للحالة |
| `feature/news-page` | صفحة أخبار فوق فرع `students` القديم | تطوير صفحة الأخبار الحالية بفلاتر قابلة للمشاركة واختبارات مستقلة |
| `login` | نموذج تسجيل دخول تجريبي يحاكي OTP وWhatsApp بلا مزود حقيقي | عدم دمجه كواجهة مضللة؛ يُنفذ لاحقًا فقط مع مزود هوية وخدمة خلفية وجلسات آمنة |
| `main-professional` | لا يحتوي فرقًا فريدًا عن تاريخ `main` الحالي | لا حاجة إلى PR شكلي |
| `feature/palestine-around-me` | دُمج سابقًا في `main` | تحسينه عبر فرع صيانة منفصل مبني على `main` |

## معيار القبول

كل فرع بديل يجب أن يجتاز فحص الأسرار، ESLint، Vitest، وبناء الإنتاج قبل الدمج.

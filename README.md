# فلسطين الآن

منصّة ويب فلسطينية موحّدة تجمع الأخبار والوظائف والطلاب والاقتصاد والتكافل والطرق والطوارئ في تجربة عربية سريعة ومتجاوبة.

هذه النسخة هي **عرض منتج احترافي**. البيانات الحالية نموذجية وليست تغذية حية؛ وقد وُسمت الواجهة بذلك بوضوح لحماية ثقة المستخدم إلى حين ربط مصادر رسمية ونظام تحرير فعلي.

## ما الذي يميز النسخة الحالية؟

- بحث موحّد يعمل داخل جميع مجموعات البيانات دون إرسال استعلام المستخدم إلى طرف خارجي.
- صفحات مستقلة للأخبار والوظائف والطلاب والاقتصاد والتكافل والطرق والطوارئ.
- صفحة «فلسطين حولي» تبني موجزاً شخصياً حسب المحافظة والاهتمامات، وتحفظ التفضيلات محلياً على جهاز المستخدم.
- تصفية وبحث وحالات فارغة وتفاصيل تفاعلية مناسبة للهاتف والحاسوب.
- تحميل كسول للصفحات وتقسيم تلقائي للحزم عبر Vite.
- دعم كامل لاتجاه RTL، تنقل بلوحة المفاتيح، رابط تخطي، واحترام `prefers-reduced-motion`.
- لا مفاتيح API داخل المتصفح، ولا تسجيل دخول أو إشعارات أو قنوات تواصل وهمية.
- اختبارات لوظيفة البحث، فحص ESLint، بناء إنتاج، وتدقيق اعتماديات ضمن مسار CI.

## التشغيل محليًا

يتطلب Node.js 22 أو أحدث.

```bash
npm ci
npm run dev
```

فحص الجودة الكامل:

```bash
npm run check
npm audit --omit=dev
```

إنشاء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

### فلسطين حولي

المسار `/my-palestine` يجمع المحتوى الموجود في المنصة داخل موجز واحد قابل للتخصيص. لا يطلب الموقع الموقع الجغرافي الدقيق، وتُحفظ المحافظة والاهتمامات داخل `localStorage` على جهاز المستخدم فقط. تعتمد النسخة الحالية على بيانات العرض نفسها، لذلك تبقى تنبيهات الثقة ظاهرة ولا تُقدّم البيانات على أنها حية.

## قواعد الأمان والثقة

- لا تضف أسرارًا إلى متغيرات تبدأ بـ `VITE_`؛ هذه المتغيرات عامة وتدخل إلى حزمة المتصفح.
- أي ذكاء اصطناعي أو تكامل مدفوع يجب أن يمر عبر خادم موثوق مع تحديد معدّل الاستخدام والتحقق من المدخلات.
- بيانات الطرق والطوارئ والأسعار والأخبار تحتاج مصدرًا رسميًا، طابعًا زمنيًا، وسياسة تصحيح قبل الإطلاق العام.
- التبرعات والتقديم للوظائف والمصادقة تبقى معطّلة حتى إضافة خدمات خلفية موثوقة ومراجعة قانونية.
- لا تطلب مستندات شخصية قبل توفير تشفير أثناء النقل، تخزين آمن، حذف واضح، وسياسة خصوصية.

## الطريق إلى منتج تجاري

1. **طبقة البيانات:** موصلات لمصادر رسمية، مراقبة فشل، سجل تحديث، وتخزين مؤقت.
2. **نظام التحرير:** لوحة إدارة، أدوار وصلاحيات، مراجعة قبل النشر، وسجل تعديلات.
3. **الحسابات:** مصادقة حقيقية، موافقة صريحة، إدارة جلسات، واستعادة حساب آمنة.
4. **العمليات:** مراقبة الأخطاء، تحليلات تحترم الخصوصية، نسخ احتياطي، وخطة استجابة للحوادث.
5. **الامتثال:** شروط استخدام، سياسة خصوصية، سياسة تصحيح، ومراجعة قانونية للتبرعات والبيانات الصحية.
6. **الجودة:** اختبارات وحدة وتكامل ومتصفح، تدقيق وصولية، وميزانية أداء لكل صفحة.

## ملاحظة حول البيانات

الأرقام والمواعيد والقصص الموجودة في `src/data` مخصصة لتوضيح تجربة الواجهة. لا يجوز نشرها على أنها معلومات حية أو استخدامها لاتخاذ قرار مالي أو طبي أو قرار سفر.
